# Roblox Halloween Piñata Event

This project is a Roblox script designed for a Halloween Piñata event. It includes scripts to spawn piñatas, teleport players to them, and provide a GUI with on/off and moveable buttons for controlling the piñata.

## Install

1. Place the piñata model in ReplicatedStorage and name it "PiñataModel".
2. Add the `PiñataSpawner.server.lua` script to ServerScriptService.
3. Add the `PiñataGUI.client.lua` script to StarterPlayerScripts.

## Use

1. The piñata will spawn automatically.
2. Players will be teleported to the piñata.
3. Use the GUI to turn the piñata on/off and move it.
